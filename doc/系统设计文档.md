## 1. 项目概述

### 1.1 项目简介

本项目是一个基于卷积神经网络（CNN）的手写数字识别系统，采用 PyTorch 深度学习框架实现。系统包含完整的训练和推理功能，支持本地部署，同时提供友好的 Web 界面供用户进行手绘数字识别。

### 1.2 核心特性

- **高精度识别**：在 MNIST 数据集上测试准确率达到 98.59%
- **GPU 加速支持**：训练和推理均支持 CUDA GPU 加速
- **Web 界面**：提供 HTML5 Canvas 手绘界面
- **实时统计**：记录每日识别次数
- **轻量级架构**：模型大小仅约 10MB

### 1.3 技术栈

| 组件 | 技术选型 |
|------|----------|
| 深度学习框架 | PyTorch 2.7.1+cu118 |
| Web 框架 | Flask 3.0.3 |
| 图像处理 | Pillow, torchvision |
| 数据处理 | Pandas, NumPy |
| 部署方式 | Docker / 本地 Python |

## 2. 模型原理

### 2.1 卷积神经网络（CNN）基础

卷积神经网络是一种专门用于处理网格状数据（如图像）的深度学习模型。其核心思想包括：

- **局部感受野**：每个神经元只连接到输入的局部区域
- **权值共享**：同一特征图使用相同的卷积核
- **层级表示**：通过多层网络自动学习层次化特征

### 2.2 模型架构详解

本系统使用的 `SimpleCNN` 模型架构如下：

```
输入图像 (3×28×28)
    ↓
[卷积块 1]
├─ Conv2d(3→32, 3×3, padding=1)  # 保持尺寸
├─ ReLU
└─ MaxPool2d(2×2)  # 尺寸减半 → 32×14×14
    ↓
[卷积块 2]
├─ Conv2d(32→64, 3×3, padding=1)  # 保持尺寸
├─ ReLU
└─ MaxPool2d(2×2)  # 尺寸减半 → 64×7×7
    ↓
[展平]
Flatten → 64×7×7 = 3136
    ↓
[分类器]
├─ Linear(3136 → 128)
├─ ReLU
├─ Dropout(0.5)
└─ Linear(128 → 10)
    ↓
输出 (10个类别概率)
```

### 2.3 各层功能说明

#### 2.3.1 卷积层（Conv2d）

**作用**：提取图像特征

```python
nn.Conv2d(in_channels=3, out_channels=32, kernel_size=3, padding=1)
```

- `in_channels=3`：输入是 3 通道 RGB 图像
- `out_channels=32`：使用 32 个不同的卷积核，提取 32 种特征
- `kernel_size=3`：卷积核大小为 3×3
- `padding=1`：边缘填充 1 像素，保持输出尺寸与输入一致

**计算公式**：
```
输出尺寸 = floor((输入尺寸 + 2×padding - kernel_size) / stride) + 1
         = floor((28 + 2×1 - 3) / 1) + 1
         = 28
```

#### 2.3.2 激活函数（ReLU）

```python
nn.ReLU()
```

**作用**：引入非线性，使网络能够学习复杂的非线性映射

**公式**：
```
ReLU(x) = max(0, x)
```

#### 2.3.3 池化层（MaxPool2d）

```python
nn.MaxPool2d(kernel_size=2, stride=2)
```

**作用**：
- 降维：将特征图尺寸减半，减少计算量
- 平移不变性：对小的位置偏移不敏感

#### 2.3.4 Dropout 层

```python
nn.Dropout(0.5)
```

**作用**：随机丢弃 50% 的神经元，防止过拟合，提高模型泛化能力

#### 2.3.5 全连接层（Linear）

```python
nn.Linear(in_features=3136, out_features=128)
nn.Linear(in_features=128, out_features=10)
```

**作用**：将提取的特征映射到最终的分类空间（10个数字类别）

### 2.4 损失函数与优化器

#### 损失函数：交叉熵损失（CrossEntropyLoss）

```python
criterion = nn.CrossEntropyLoss()
```

适用于多分类任务，公式：
```
Loss = -Σ(真实标签 × log(预测概率))
```

#### 优化器：Adam

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

自适应学习率优化器，结合了 AdaGrad 和 RMSProp 的优点。

## 4. 数据集介绍

### 4.1 MNIST 数据集

MNIST（Modified National Institute of Standards and Technology）是经典的手写数字数据集。

| 属性 | 数值 |
|------|------|
| 数据集来源 | NIST 数据库 |
| 样本数 | 70,000 |
| 训练集 | 60,000 张 |
| 测试集 | 10,000 张 |
| 图像尺寸 | 28×28 像素 |
| 图像格式 | 灰度图 |
| 标签 | 0-9（10个类别） |

### 4.2 数据集预处理

#### 原始格式（idx1-ubyte）

```
train-images-idx3-ubyte  # 训练图像
train-labels-idx1-ubyte  # 训练标签
t10k-images-idx3-ubyte   # 测试图像
t10k-labels-idx1-ubyte   # 测试标签
```

#### 转换后的格式

**CSV 文件结构**（[train.csv](file:///d:\workspace_ai\CNNSession\data\cnn\MNSIT\CONV\train.csv)）：

```csv
filename,label
0.png,5
1.png,0
2.png,4
3.png,1
...
```

**图像存储**：
- `train-images/`：60,000 张训练图像
- `test-images/`：10,000 张测试图像

### 4.3 数据预处理流水线

```python
transforms.Compose([
    transforms.Resize((28, 28)),           # 统一尺寸
    transforms.ToTensor(),                 # → [0, 1]
    transforms.Normalize((0.1307,), (0.3081,))  # 标准化
])
```

**标准化参数**：
- 均值：0.1307（MNIST 数据集均值）
- 标准差：0.3081（MNIST 数据集标准差）

## 5. 训练流程

### 5.1 配置参数

**配置文件**：[config.json](file:///d:\workspace_ai\CNNSession\CNNTrainer\config.json)

```json
{
    "cnn": {
        "data_dir": "d:/workspace_ai/CNNSession/data/cnn/MNSIT/CONV",
        "classes": 10,
        "batch_size": 256,
        "epochs": 5,
        "lr": 0.001,
        "use_gpu": true
    }
}
```

**参数说明**：

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `data_dir` | 数据集路径 | 根据实际修改 |
| `classes` | 分类数量 | 10（0-9） |
| `batch_size` | 批次大小 | 256（GPU）/ 32（CPU） |
| `epochs` | 训练轮数 | 5-10 |
| `lr` | 学习率 | 0.001 |
| `use_gpu` | 是否使用 GPU | true/false |

### 5.2 训练流程详解

```
开始
  ↓
[1] 读取配置文件
  ↓
[2] 设备选择
    ├─ GPU 可用 → 使用 CUDA
    └─ GPU 不可用 → 使用 CPU
  ↓
[3] 数据加载
    ├─ 训练集 DataLoader (batch_size=256, shuffle=True)
    └─ 测试集 DataLoader (batch_size=256, shuffle=False)
  ↓
[4] 模型初始化
    ├─ SimpleCNN(num_classes=10)
    ├─ Adam 优化器 (lr=0.001)
    └─ CrossEntropyLoss
  ↓
[5] 训练循环 (5 epochs)
    │
    ├─ [5.1] 训练阶段
    │   ├─ model.train()
    │   ├─ 批量迭代
    │   │   ├─ 前向传播
    │   │   ├─ 计算损失
    │   │   ├─ 反向传播
    │   │   └─ 参数更新
    │   └─ 打印训练指标
    │
    └─ [5.2] 验证阶段
        ├─ model.eval()
        ├─ torch.no_grad()
        └─ 计算测试准确率
  ↓
[6] 模型保存
    └─ torch.save(model, "cnn_model_full.pt")
  ↓
结束
```

## 6. 推理流程

### 6.1 服务启动流程

```
启动 serve.py
  ↓
初始化日志
  ↓
加载统计数据 (stats.json)
  ↓
设备选择 (GPU/CPU)
  ↓
加载模型 (cnn_model_full.pt)
  ↓
配置图像预处理 Pipeline
  ↓
注册 API 路由
  ↓
启动 Flask 服务 (http://0.0.0.0:5000)
```

### 6.2 推理请求处理流程

```
接收 POST /predict 请求
  ↓
验证模型已加载
  ↓
提取上传的图像文件
  ↓
图像预处理
  ├─ Resize(28×28)
  ├─ Grayscale → RGB (3通道)
  ├─ ToTensor → [0, 1]
  └─ Normalize(mean=0.1307, std=0.3081)
  ↓
添加批次维度 (unsqueeze)
  ↓
移动到目标设备 (CPU/GPU)
  ↓
模型推理
  ├─ torch.no_grad()  # 禁用梯度计算
  ├─ 前向传播
  ├─ argmax 获取预测类别
  └─ softmax 获取置信度
  ↓
更新今日识别次数
  ↓
返回 JSON 响应
```

### 6.3 前端绘图流程

```
用户在 Canvas 上绘制
  ↓
Canvas 事件监听
  ├─ mousedown: 开始绘制
  ├─ mousemove: 绘制线段
  └─ mouseup: 停止绘制
  ↓
点击"识别"按钮
  ↓
Canvas → Blob → File
  ↓
FormData 封装
  ↓
发送 POST /predict
  ↓
显示识别结果 + 置信度
```

## 8. 性能优化

### 8.1 GPU 加速

#### 训练加速效果

| 设备 | 每 epoch 耗时 | 相对速度 |
|------|--------------|----------|
| CPU (i7-10750H) | ~180s | 1x |
| GPU (MX350) | ~18.5s | ~9.7x |

#### 启用方式

**训练**：[config.json](file:///d:\workspace_ai\CNNSession\CNNTrainer\config.json)
```json
{
    "use_gpu": true
}
```

**推理**：[serve.py](file:///d:\workspace_ai\CNNSession\CNNAPP\serve.py#L19)
```python
USE_GPU = True
```

### 8.2 批量大小优化

| batch_size | GPU 显存 | 训练速度 |
|------------|----------|----------|
| 32 | 低 | 基准 |
| 64 | 中 | +20% |
| 128 | 中高 | +35% |
| 256 | 高 | +45% |

**推荐配置**：batch_size=256（如 MX350 可用）

### 8.3 推理优化

- **torch.no_grad()**：推理时禁用梯度计算，节省内存
- **模型 eval 模式**：关闭 Dropout 和 BatchNorm
- **预处理缓存**：避免重复计算相同的图像转换
