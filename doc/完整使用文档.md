# CNN 手写数字识别 - 完整使用文档

## 项目概述

这是一个基于 CNN（卷积神经网络）的手写数字识别系统，支持本地训练和推理，同时支持 CPU 和 GPU 模式。

## 目录结构

```
CNNSession/
├── CNNAPP/              # 推理服务
│   ├── static/
│   │   └── index.html   # 前端界面
│   ├── serve.py         # Flask 推理服务
│   └── cnn_model_full.pt # 训练好的模型
├── CNNTrainer/          # 训练脚本
│   ├── cnn_trainer.py   # 训练主程序
│   ├── config.json      # 训练配置
│   └── cnn_model_full.pt # 训练生成的模型
├── data/                # 数据集
│   └── cnn/MNSIT/CONV/  # MNIST 数据集
└── doc/                 # 文档目录
```

---

## 第一部分：本地使用方法

### 一、环境准备

#### 1. 安装依赖

```bash
pip install torch torchvision flask pandas pillow numpy
```

#### 2. 检查 CUDA（GPU 支持）

如果要使用 GPU，需要安装 CUDA 版本的 PyTorch：

```bash
# 检查 CUDA 是否可用
python -c "import torch; print('CUDA available:', torch.cuda.is_available())"
```

---

### 二、本地训练

#### 方法 1：使用 CPU 训练（默认）

```powershell
# Windows PowerShell
$env:KMP_DUPLICATE_LIB_OK="TRUE"
cd CNNTrainer
python cnn_trainer.py
```

#### 方法 2：使用 GPU 训练

修改 `CNNTrainer/config.json` 中的 `use_gpu` 为 `true`：

```json
{
    "cnn": {
        "data_dir": "d:/workspace_ai/CNNSession/data/cnn/MNSIT/CONV",
        "classes": 10,
        "batch_size": 64,
        "epochs": 1,
        "lr": 0.001,
        "use_gpu": true
    }
}
```

然后运行训练：

```powershell
$env:KMP_DUPLICATE_LIB_OK="TRUE"
cd CNNTrainer
python cnn_trainer.py
```

#### 训练配置说明

在 `CNNTrainer/config.json` 中可以调整：

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `data_dir` | 数据集路径 | 根据实际情况修改 |
| `classes` | 分类数量 | 10（0-9） |
| `batch_size` | 批次大小 | 64（GPU）或 32（CPU） |
| `epochs` | 训练轮数 | 1-10 |
| `lr` | 学习率 | 0.001 |
| `use_gpu` | 是否使用 GPU | true/false |

#### 训练结果

训练完成后，模型将保存在：
- `CNNTrainer/cnn_model_full.pt`

需要手动复制到推理目录：
```powershell
Copy-Item CNNTrainer/cnn_model_full.pt CNNAPP/cnn_model_full.pt -Force
```

---

### 三、本地推理服务

#### 方法 1：使用 CPU 推理（默认）

```powershell
$env:KMP_DUPLICATE_LIB_OK="TRUE"
cd CNNAPP
python serve.py
```

服务将在 `http://127.0.0.1:5000` 启动。

#### 方法 2：使用 GPU 推理

修改 `CNNAPP/serve.py` 中的 `USE_GPU` 为 `True`：

```python
# 在 serve.py 文件顶部
USE_GPU = True  # 设置为 True 使用 GPU，False 使用 CPU
```

然后运行服务：

```powershell
$env:KMP_DUPLICATE_LIB_OK="TRUE"
cd CNNAPP
python serve.py
```

#### 服务验证

打开浏览器访问：
- **主界面**：http://127.0.0.1:5000
- **健康检查**：http://127.0.0.1:5000/health
- **统计信息**：http://127.0.0.1:5000/stats

## 第二部分：服务器部署

### 一、需要修改的文件

#### 1. `CNNTrainer/config.json`

```json
{
    "cnn": {
        "data_dir": "/data/cnn/MNSIT/CONV",  // 修改为 Linux 路径
        "classes": 10,
        "batch_size": 64,
        "epochs": 1,
        "lr": 0.001,
        "use_gpu": true  // 根据服务器 GPU 情况设置
    }

```

#### 2. `.env` 文件

```env
# 数据目录（Linux 路径）
DATA_DIR=/data/cnn/MNSIT/CONV
```

#### 3. Docker 相关

如果使用 Docker 部署：

- `Dockerfile`：确保已配置好
- `docker-compose.yml`：确保挂载路径正确

```bash
cd CNNTrainer

# 运行训练

cp cnn_model_full.pt ../CNNAPP/
```

## 第三部分：GPU 模式详细说明

### 一、GPU 环境检查

在使用 GPU 之前，请确保：

#### 1. 检查 CUDA 可用性

```python
import torch
print("CUDA available:", torch.cuda.is_available())
print("CUDA version:", torch.version.cuda)
print("GPU count:", torch.cuda.device_count())
if torch.cuda.is_available():
    print("GPU name:", torch.cuda.get_device_name(0))
```

#### 2. 如果没有 CUDA

安装 CUDA 版本的 PyTorch：

```bash
# 访问 https://pytorch.org/get-started/locally/ 获取最新命令
# 示例（根据你的 CUDA 版本调整）：
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

---

### 二、GPU 训练模式

训练代码已自动支持 GPU，只需在配置中设置 `"use_gpu": true`。

**GPU 训练的优势：**
- 训练速度快 10-50 倍（取决于 GPU 型号）
- 可以使用更大的 batch_size
- 支持更深的网络结构

**推荐配置：**
- 入门级 GPU（如 GTX 1060）：batch_size=32
- 中端 GPU（如 RTX 3060）：batch_size=64
- 高端 GPU（如 RTX 3090/A100）：batch_size=128 或更大

---

### 三、GPU 推理模式

推理代码支持 GPU，只需在 `serve.py` 中设置 `USE_GPU = True`。

**GPU 推理的优势：**
- 单次推理延迟更低
- 支持批量推理
- 高并发场景性能更好

## 第四部分：常见问题与注意事项

### 一、Windows 环境常见问题

#### 1. `ModuleNotFoundError`

确保已安装所有依赖：
```powershell
pip install torch torchvision flask pandas pillow numpy
```

#### 2. `OMP: Error #15`

设置环境变量：
```powershell
$env:KMP_DUPLICATE_LIB_OK="TRUE"
```

#### 3. 端口 5000 被占用

修改 `serve.py` 中的端口，或终止占用进程：
```powershell
netstat -ano | findstr :5000
taskkill /PID <进程ID> /F
```

---

### 二、Linux 环境常见问题

#### 1. 权限问题

确保数据目录有读写权限：
```bash
chmod -R 755 data/
```

#### 2. 内存不足

减小 `batch_size`，或使用 swap 分区。

---

### 三、GPU 相关问题

#### 1. CUDA out of memory

- 减小 `batch_size`
- 减小模型规模
- 关闭其他占用 GPU 的程序

#### 2. GPU 未被识别

- 检查 GPU 驱动是否正确安装
- 确认安装的是 CUDA 版本的 PyTorch
- 运行 `nvidia-smi` 检查 GPU 状态

---

### 四、数据与模型注意事项

#### 1. 数据集位置

确保 `data_dir` 指向正确的路径，包含：
- `train.csv` / `test.csv`
- `train-images/` / `test-images/`

#### 2. 模型文件

- 训练后的模型需要手动复制到推理目录
- 模型文件较大（约 10MB），注意磁盘空间

#### 3. 版本兼容性

- PyTorch 版本建议 >= 2.0
- Python 版本建议 >= 3.8

## 第五部分：快速开始指南

```powershell

$env:KMP_DUPLICATE_LIB_OK="TRUE"
cd CNNAPP
python serve.py
```

```powershell

cd CNNTrainer

$env:KMP_DUPLICATE_LIB_OK="TRUE"
python cnn_trainer.py

# 4. 复制模型
Copy-Item cnn_model_full.pt ../CNNAPP/cnn_model_full.pt -Force

```

```powershell
# 训练
```
