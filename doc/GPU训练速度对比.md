
# CPU vs GPU 训练速度对比测试

## 测试环境

- **GPU**: NVIDIA GeForce MX350
- **CUDA版本**: 11.8
- **PyTorch版本**: 2.7.1+cu118

## 测试配置

- **模型**: SimpleCNN (2层卷积 + 2层全连接)
- **数据集**: MNIST手写数字
- **Batch size**: 256
- **Epochs**: 2

---

## 测试结果

### 1. 模拟数据测试

| 设备 | 总耗时 | 速度 | 加速比 |
|------|--------|------|--------|
| **CPU** | 12.86秒 | 1,990.8 样本/秒 | 基准 |
| **GPU (MX350)** | 1.33秒 | 19,213.7 样本/秒 | **9.7x** 🚀 |

**结论**: GPU比CPU快 **9.7倍**！

---

## GPU 性能分析

### 为什么 GPU 利用率可能不高？

1. **模型太简单**: SimpleCNN 的计算量相对较小，GPU还没全力工作就完成了
2. **Batch size 小**: 虽然我们设置了256，但更大的模型可能需要更大的batch size
3. **数据加载瓶颈**: 从磁盘读取图片的时间可能超过GPU计算时间

### 如何让 GPU 发挥更大性能？

1. **增加模型复杂度**: 使用 ResNet、VGG 等更深的网络
2. **增大 Batch size**: 只要显存足够，越大越好
3. **增加训练数据**: 使用更大的数据集
4. **增加 Epochs**: 训练时间越长，加速效果越明显

---

## 如何使用 GPU 加速

### 训练时启用 GPU

修改 `CNNTrainer/config.json`:

```json
{
    "cnn": {
        "use_gpu": true,
        "batch_size": 256
    }
}
```

### 推理时启用 GPU

修改 `CNNAPP/serve.py` 顶部:

```python
USE_GPU = True
```

---

## 监控 GPU 使用

打开任务管理器 -&gt; 性能 -&gt; GPU 1 (NVIDIA GeForce MX350):

- **GPU 利用率**: 越高越好（理想状态70-100%）
- **GPU 显存使用**: 显示模型和数据占用的显存
- **GPU 温度**: 注意散热

---

## 总结

- **GPU加速效果显著**: 在相同任务下，MX350 比 CPU 快近10倍
- **配置简单**: 只需修改一个配置项
- **推荐使用**: 只要有NVIDIA GPU，建议始终用GPU模式训练和推理
